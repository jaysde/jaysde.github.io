# jaysde.github.io

Personal website of Jay Suthar: a single static `index.html` (no build step), served by GitHub Pages.

- The old Hugo site is saved on the `old-site` branch.
- Edit content directly in `index.html`.
- Add a photo as `profile.png` in the repo root (initials are shown until then).
- `JaySuthar_CV.pdf` is linked from the **CV** button.
